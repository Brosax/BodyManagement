# 手动验收清单

部署完成后，两人各用一台手机逐项勾选。

## 首次安装与身份

- [ ] 手机浏览器打开网址，出现「今天你是谁？」身份选择
- [ ] 选择身份后进入首页；杀掉浏览器重开，身份保持不变
- [ ] 「我」Tab 可以切换身份，切换后首页数据随之变化
- [ ] 右上角徽标可快速切换查看对方数据

## 卡路里（吃）

- [ ] 「＋」手动添加食物：选餐次、名称、热量，保存后列表即时更新
- [ ] 点击某条记录可修改并保存；✕ 可删除（有确认提示）
- [ ] 顶部合计与进度条正确累加、超过目标变橙色
- [ ] 「‹ 前一天 / 后一天 ›」可以翻看历史日期，未来日期按钮不可点
- [ ] **拍照识别**：拍一张食物照片 → 显示识别中 → 返回的食物名、热量和估算说明可确认/修改 → 保存后条目带「AI识别」标记
- [ ] AI 识别的条目在列表显示缩略图，点击打开全屏大图 + 估算说明
- [ ] 手动输入的记录没有照片，纯文字展示
- [ ] 断网时提交失败有错误提示，且输入内容不丢失

## 蛋白粉打卡与推送

- [ ] 首页点「打卡」变为 ✅ 已完成；「取消打卡」可撤销
- [ ] iOS：先「添加到主屏幕」，从主屏幕打开后再开通知
- [ ] 「我」Tab 打开通知开关 → 系统弹出通知授权 → 允许后开关保持绿色
- [ ] 到达提醒时间（北京时间 15:00）收到系统推送「蛋白粉时间到啦」
- [ ] 点推送跳转到 App；当天已打卡的人**不会**收到推送

## 训练（练）

- [ ] **日历**：顶部显示本周 7 天横条，每格有日期 + 计划简写（休/动作名前 4 字）+ 打卡圆点
- [ ] 「展开月历」可翻看整月，‹ › 切换上/下月；今天绿色高亮
- [ ] 点击任意过去日期 → 下方详情切换为该天的计划全文与状态
- [ ] 选中过去日期可「补记这天打卡」，记录落在选中日期上
- [ ] 周计划编辑器：点击任意一天填写动作，离开输入框自动保存（刷新后仍在）
- [ ] 今天对应的天高亮；首页「今天练什么」显示当天模板内容
- [ ] 「完成打卡」后显示 ✅；训练历史出现该记录
- [ ] 「自由记录」可添加不带计划的训练并出现在历史里
- [ ] 历史记录可删除

## 记重量（练 · 结构化记录）

- [ ] 「🏋️ 记重量」打开底部抽屉，出现内置动作联想（如搜「卧推」出「杠铃卧推」）
- [ ] 历史上记过的自定义动作也会出现在联想列表
- [ ] 选动作后逐组填 次数×重量，「＋添加一组」「＋添加动作」可连续录入多个动作
- [ ] 已录过的动作显示「上次 X月X日：10×50kg，…」对比行
- [ ] 同一天再次保存提示「整体替换当天记录」，替换后旧数据被覆盖
- [ ] 日历详情页「重量记录」区显示当天的逐组数据，可点「编辑」修改

## 体重（重）

- [ ] 输入体重保存后显示「已记录 ✓」，今日数值出现在卡片右上
- [ ] 同一天再次录入会覆盖当天的旧数值
- [ ] 记录 ≥2 天后趋势折线正常显示；只有 1 条时显示鼓励文案

## 其他

- [ ] Android Chrome 与 iOS Safari 都能正常使用
- [ ] 弱网/飞行模式下各页面有加载或错误提示，不白屏
